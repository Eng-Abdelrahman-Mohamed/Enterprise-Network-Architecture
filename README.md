# Enterprise-Network-Architecture
Enterprise Network Architecture &amp; Simulation using Cisco Packet Tracer, featuring OSPF, EIGRP, eBGP, Route Redistribution, HSRP, SVI-based Inter-VLAN Routing, VLAN Segmentation, EtherChannel/LACP, Rapid-PVST+, DHCP, ACLs, DHCP Snooping, Port Security, Wireless Networking, and Network Redundancy.
